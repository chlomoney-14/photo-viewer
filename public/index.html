Download JPG previews from Google Drive

How to get a free API key (5 minutes, once)
  1. Open Google Cloud Console and create a project (any name).
  2. Turn on the Google Drive API for it.
  3. Go to Credentials › Create credentials › API key, and copy it.
  4. Edit the key: under Website restrictions add , and under API restrictions pick Google Drive API.

The key only lets this app list files in folders shared as “Anyone with the link”. It’s saved on this device.

Photos are saved in this browser on this device and work offline. On iPhone, tap Share › Add to Home Screen and open it from there, so iOS keeps them.

Save an offline copy

Downloads a .zip of 2048 px JPGs to this device, with a Starred folder holding everything starred so far on any device. It works with no connection to the Mac. Download again later to pick up newer stars.

Where it is: in the Files app, under Downloads. On iPhone that’s usually iCloud Drive › Downloads, or On My iPhone › Downloads if iCloud Drive is off (Settings › Apps › Safari › Downloads shows which). On Android it’s Files › Downloads.

To view it anywhere, no Wi-Fi needed: tap the .zip once to unzip it. That makes a folder with Starred (and All) inside. Open a photo and swipe through them, or select them and choose Save to Photos.
